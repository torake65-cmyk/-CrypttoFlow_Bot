# CryptoFlow Bot

A Telegram bot for cryptocurrency price tracking and alerts.

## Features
- Real-time crypto price checks
- Custom price alerts
- 100+ cryptocurrencies supported
- Non-custodial - no financial transactions

## Quick Deploy to Railway

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template)

## Local Development

```bash
# Install dependencies
npm install

# Set up environment
cp .env.example .env
# Add your bot token to .env

# Run bot
npm start
